# 信号检测论体验交互式平台

这是一个纯前端课程作业，使用 HTML、CSS、JavaScript 和 Canvas 实现，无需安装依赖。

## 运行方法

直接双击 `dist/index.html`，或使用任意静态文件服务器打开 `dist` 目录。

## 功能

- 姓名与学号登录、游客登录
- 教师账号登录（账号 `admin666`，密码 `SDTliyun666`）
- 雷达监测、医学影像、纹理异常三种任务
- 难度滑块 d′=0.5–3.5，以及困难（0.8）、默认（1.7）、简单（3.0）快捷设置
- 每个任务 20 试次，每次刺激显示约 1.2 秒，逐试次反馈
- 自动计算 H/M/FA/CR、P(H)、P(FA)、d′、β、c、准确率、平均反应时
- 雷达亮点仅在扫描线经过时短暂出现；影像包含正常亮斑干扰；纹理包含轻微方向扰动
- 结果页、教师后台及 CSV 标明：P(H)、P(FA) 为原始比率，d′、β、c 使用 0.5 次试次修正率
- 混淆矩阵与 ROC 结果图
- 概念实验室：分布与判断标准、混淆矩阵、SDT 指标、ROC 与 zROC、先验概率与最优 β、支付矩阵、SDT 与机器学习、警觉衰退模拟
- 教师后台汇总浏览器本地保存的实验记录
- 难度设置与实测d′分开标示；CSV包含试次数、实际信号比例和从刺激隐藏后起算的平均反应时；后台汇总采用各局平均值（各局同权）
- 页面上方依次呈现侧视综合发球任务、接球方视角任务；原有雷达、影像、纹理三项任务在下方
- 两个乒乓球任务均可选 20–100 的任意整数试次（包括奇数），与其他三项任务共用首页右上角的统一难度设置 0.5–3.5
- 乒乓球采用 Canvas 程序动画，资源在 `dist/pingpong.js` 和 `dist/receiver.js` 中，无需外部视频、网络或素材服务；每次呈现 3.6 秒，隐藏后用 F（违规）/ J（合规）作答
- 接球方视角只考察击球遮挡与向身体方向回抛；回抛违规为与垂直线夹角超过30°，通过正面透视和小侧视图呈现
- 八类动画：抛球高度、手掌状态、抛球角度、端线前后击球、遮挡、双打半区、落台顺序、直接出界；完整指导语在实验开始前呈现
- 违规为信号，合规为噪声；信号数为 floor(N/2)，噪声数为 N-floor(N/2)，随机排列。记录包含实际试次数、信号概率、逐试次判断、反应时、动画类型和随机种子
- 难度设置控制视觉线索的幅度，不保证与结果实测 d′ 相等；发球教学判定依据用户提供的指导语（含30°阈值），不作为正式赛事执裁规则认证

## 文件结构

- `dist/index.html`：页面与完整指导语
- `dist/app.js`：原有任务、SDT 计算、概念实验室和教师后台
- `dist/pingpong.js`：独立发球任务、参数化动画、试次生成和结果整合
- `dist/receiver.js`：接球方视角动画、遮挡与回抛参数、对应指导语
- `dist/styles.css`、`lab.css`、`metrics.css`、`pingpong.css`：布局与样式
- `作业要求核对.md`：对文件夹中两张作业要求图片的逐项核对
