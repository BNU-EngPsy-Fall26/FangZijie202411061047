# 信号检测论体验交互式平台

本作业使用 HTML、CSS、JavaScript 和 Canvas 实现，无需安装依赖。

## 运行方法

直接双击 `dist/index.html`，或使用任意静态文件服务器打开 `dist` 目录。

## 功能

- 姓名与学号登录、游客登录
- 教师账号登录（账号 `admin666`，密码 `SDTliyun666`）
- 雷达监测、医学影像、纹理异常三种任务
- 难度滑块 d′=0.5–3.5，以及困难（0.8）、默认（1.7）、简单（3.0）快捷设置
- 每个任务 20 试次，每次刺激显示约 1.2 秒，逐试次反馈
- 自动计算 H/M/FA/CR、P(H)、P(FA)、d′、β、c、准确率、平均反应时
- 雷达亮点仅在扫描线经过时短暂出现；影像包含正常亮斑干扰；纹理包含轻微方向扰动
- 结果页、教师后台及 CSV 标明：P(H)、P(FA) 为原始比率，d′、β、c 使用 0.5 次试次修正率
- 混淆矩阵与 ROC 结果图
- 概念实验室：分布与判断标准、混淆矩阵、SDT 指标、ROC 与 zROC、先验概率与最优 β、支付矩阵、SDT 与机器学习、警觉衰退模拟
- 教师后台汇总浏览器本地保存的实验记录

## 数据说明

本作业为纯前端版本，实验记录保存在浏览器 `localStorage`。更换浏览器、使用无痕模式或清除网站数据后，记录会消失。
