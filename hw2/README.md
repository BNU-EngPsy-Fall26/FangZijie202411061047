# 作业二 · 星际快递局

三项实验：Horrey 等（2006）SEEV 驾驶注意、Aretz（1991）地图方向判断、Shepard–Metzler（1971）心理旋转；前两篇课程推荐，第三篇新增。为主题改编，非完整原始方法复现。

## 运行与验证

在线用电脑 Chrome/Edge，允许摄像头并校准。无需安装 Node。源码本地运行：在 hw2 目录执行 node server.mjs，打开 http://localhost:4173。测试：npm test。模块需 HTTP，不能以 file:// 直接打开 dist/index.html。

## 改进与收数前预测

完整依据、操作与预测见 [实验改进-v4.md](实验改进-v4.md)。当前提交记录本版计划，不倒签为此前试测前的预注册。

| 实验 | 对照与改进 | 预测与指标 |
|---|---|---|
| SEEV | 普通仪表 vs 注视自适应仪表；600 ms 未采样到仪表、信号有效时增强外圈 | 结合价值 V 与显著性 S，预测仪表正确 RT 降低；检查正确率、首次仪表采样和触发比例 |
| 地图 | 普通北向上、航向向上、北向上＋注视自适应扇形 | 静态 wedge 源自原文，创新是注视触发增强时机；预测相对北向上降低 RT，检查正确率 |
| 旋转 | 无共同参照框 vs 两侧同尺度网格＋XYZ 轴 | 外部参照辅助空间编码，预计同形 RT 降低，斜率变化为探索；模型不动，不标镜像答案 |

600 ms 为本版参数，不是原文阈值。效果需真实数据检验。
