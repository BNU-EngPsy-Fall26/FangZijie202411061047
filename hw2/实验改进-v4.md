# 三项实验的可检验改进（2026-11-03）

三项保留原试次数、练习上限与 RT 计时规则；新旧协议分开分析。

| 实验 | 原文基础 | 本版改进与对照 | 预测与主要指标 |
|---|---|---|---|
| 驾驶 / SEEV | 任务价值与视觉扫描，原文并未使用本版离散温度/速度告警 | 普通仪表 vs 注视自适应仪表；仪表事件出现后 600 ms 仍没有仪表区采样，且实时信号有效时增强外圈。火箭不出现文字提示，空格作答保留 | 结合 V 与 S 的遗漏补偿假设：仪表事件正确 RT 降低；同时检查正确率与触发次数、首次仪表区采样延迟 |
| 地图 / Aretz | 原文已有 north-up、track-up 和静态 wedge | 保留普通北向上和航向向上；改进条件为北向上＋注视自适应扇形，600 ms 未采样到地图且信号有效时增强扇形边界。不会显示正确应答方向 | 外部参照加上注视触发显著性，预计相对北向上降低 RT；报告正确率、首次地图区采样延迟和辅助触发比例 |
| 心理旋转 / Shepard–Metzler | 原文考察无辅助结构的立体形状判断与 RT–角度关系 | 无共同参照框 vs 两侧同尺度网格＋XYZ轴；模型不动，不给镜像答案标记 | 外部共同参照辅助空间编码，预计降低同形 RT；角度斜率变化作探索，正确率检查速度准确率权衡 |

这些是待检验的假设。地图的静态扇形本身是原文元素，不能称为本项目创新；创新是注视触发时机。旋转辅助的效果也未由原文证明，不将假设写成已知有效的规律。600 ms 为本版工程参数，正式收数前需真人试测确认，不是原论文给出的阈值。

协议：驾驶 starparcel-v4-adaptive-2026-11-03；地图 starparcel-v3-map-adaptive-2026-11-03；旋转 starparcel-v3-common-frame-2026-11-03。驾驶主比较只纳入仪表事件（温度/速度），道路事件维持任务负荷，不把没有辅助的道路事件误当仪表改进的效果。

眼动指标为采样坐标落入大区域，不是专业注视事件检测。误差只记录，不拦截，但无真实眼动信号不能运行采集；丢失信号不会触发自适应。记录首次区域采样和辅助触发，不能将它们写成已证实的注意或理解。

新任务只有摄像头采集。开始前勾选同意匿名编号、行为与眼动摘要发送到课程项目；完整坐标留在本机 JSON。完成后自动尝试上传，仅服务器 ok 回执显示成功。失败本机仍有数据，核验老师后台后可手动重试；成功状态本机记忆以防重复。低中档上传标记 pilot，不计入完整版正式人数。旧记录不自动补传。

未进行真人摄像头与生产服务器端到端验证；没有向课程项目发送模拟被试。当前已上传课程 GitHub 并部署 Pages，有设计预测提交；后续正式收数须在此提交之后开展，不能对以前试测倒签预注册。
